V1 mark iterations plus two layout directions for Home, News and Mail, in light and dark. Telemetry moves out of the status bar and into a popover; the composer puts the prompt first; the agent panel folds to a strip.

02 · Screens

Home

Status bar removedModel, Gemma state, model roster, sources in context, KB queue and mail processing now live behind the pulse icon. A green dot on the icon stays visible when everything is healthy; it turns amber on errors.
Sidebar as accordionHome, command bar and new conversation become three icons under the mark. Pinned (Mail, News, user pins), Conversations, Sources and Archived each collapse. Brain, settings and telemetry sit at the bottom.
Prompt firstThe composer is one line: attach, prompt, model chip, send. Suggestions drop to a faint row below it and never wrap.
Agent on the sideThe on-tab agent folds to a 44px strip. Click its header button or the strip to toggle. Home opens with it folded, News and Mail with it open.
A · Floating vs B · FlushA floats main and agent as 12px-radius cards on a tinted canvas with the sidebar on the canvas. B runs edge to edge with hairlines, and keeps radius only on bars, inputs and chips.
Terminal heritage keptMono stays for data: timestamps, trust scores, counts, the address bar and shortcut hints. Labels like [open reader] become plain text actions.
