## 1. Problem & Goal
After pulling `v0.5.1` (`6bf9d71`) onto macOS, three classes of work and cross-platform gaps remain outstanding:
1. **macOS Release Gate & Runtime Blockers:**
   - `sidecar/test_i18n.py:191` fails on macOS because `self.rt.i18n.i18n_dir` resolves `/var` -> `/private/var` while `self.temp_dir / "i18n"` is unresolved.
   - Most sidecar tests write unmocked entries to the real OS Keychain (`service="satz-browser"`), polluting `login.keychain-db` and crashing with `keyring.errors.PasswordSetError (-25244)` (`errSecInvalidOwnerEdit`) when run under adhoc-signed `python-runtime/bin/python3.12` (the exact binary shipped in unsigned macOS preview bundles). Production `sidecar/satz_passwords.py` also lacks `-25244` recovery if an unsigned `.app` collides with a preexisting keychain slug.
   - `../sgs/.venv/bin/python` on Mac lacks `pillow` (`PIL`), failing 4 `sidecar/test_web_harness.py` image tests without a local `.venv` matching `sidecar/requirements-runtime.txt`.
2. **Open Plan Items (`v0.13` & `v0.10`):**
   - Finish `v0.13-browser-telemetry`: implement opt-in HTTPS batch uploader (`flush_hosted_sync` + `POST /telemetry/sync`) in `sidecar/satz_telemetry.py` / `sidecar/satz_models.py` and surface the local telemetry inspector + opt-in hosted sync UI in Settings (`src/knowledge.ts`, `src/api.ts`, `src/main.ts`, `src/i18n/catalog.ts`).

3. **Local Mac Packaging & Upstream Dev-Loop Prevention:**
