## 1. Objective
Provide every installed Satz Browser instance with an automatic, privacy-preserving local `dev/` workspace inside its OS AppData directory (`%APPDATA%\com.satz.browser\dev\` on Windows, `~/Library/Application Support/com.satz.browser/dev/` on macOS, `~/.local/share/com.satz.browser/dev/` on Linux) to record structured feature/harness analytics and eval outcomes cleanly, ready for future opt-in hosted aggregation.

## 2. Architecture
1. **Per-Instance Local Storage (`sidecar/satz_telemetry.py`):**
   - `instance.json`: per-install UUID, OS/arch, app semver, schema version, opt-in hosted endpoint settings (`hosted_sync_enabled: false` by default).
   - `analytics/telemetry.sqlite` & `events.jsonl`: scrubbed metrics per subsystem (`sidecar`, `chat_harness`, `mail`, `news`, `satz_tools`, `evals`, `updater`, `shell`).
   - `evals/`: local eval snapshots and captured failure metrics.
2. **Privacy & Redaction:**
   - Strips emails, local user home directories, raw URL paths, secrets/tokens, API keys, and raw prompt/email bodies prior to disk persistence.
3. **Sidecar Endpoints (`sidecar/satz_models.py`):**
   - `GET /telemetry/summary`: local rollup counts, error rates, and recent eval runs.
   - `GET /telemetry/export`: hosted-ready sequential batch of unexported events.
   - `POST /telemetry/event`, `POST /telemetry/ack`, `POST /telemetry/config`: ingest frontend events, advance export cursors, and toggle opt-in HTTPS endpoint shipping.
4. **Future Hosted Ingestion:**
   - Because batches follow a strict versioned envelope with monotonic `seq` acknowledgments (`/telemetry/export` + `/telemetry/ack`), enabling hosted cloud aggregation requires only an authenticated HTTPS batch uploader honoring `hosted_sync_enabled`.
