## 1. Scope Evolution (`v1 -> v2`)
`v1` implemented `sidecar/satz_telemetry.py`, `<app_data_dir>/dev/` layout, PII scrubbing, SQLite `telemetry_events` + `eval_snapshots`, and `/telemetry/summary`, `/telemetry/export`, `/telemetry/event`, `/telemetry/ack`, `/telemetry/config`.
`v2` completes the remaining two deliverables in `tasks.md`:
1. **Opt-In HTTPS Batch Uploader (`flush_hosted_sync` + `POST /telemetry/sync`):**
   - Strictly disabled unless `hosted_sync_enabled == true` and an `https://` (or loopback test) endpoint is configured.
   - Uses `export_pending_batch(limit=200)` + `urllib.request.urlopen` JSON `POST`, calling `mark_exported_through(max_seq)` only on HTTP 2xx responses, and tracking `last_sync_at` / scrubbed `last_sync_error` in `instance.json`.
2. **Settings Diagnostics & Telemetry UI (`src/knowledge.ts`):**
   - Renders a tokenized, localized **Diagnostics & Telemetry** card/accordion inside Settings showing the local `dev/` path, instance ID prefix, total/error/unexported counts, subsystem rollup table, recent eval snapshots, and opt-in Hosted Sync controls (toggle + HTTPS endpoint + Save + Sync now + Refresh).
