## 1. Goals
Establish a dedicated `dev/` workspace inside `satz-browser` to unify engineering docs, version snapshots, analytics, Antigravity/Claude Code release governance, versioned plans, and a running **Dev Brain Graph DB** powered by Satz Brain mechanics (`registry.yaml`, `BRAIN.md`, Markdown `[[wikilinks]]`, SQLite FTS5 + graph edges, and `PlanckEncoder` embeddings).

## 2. Structure
1. `dev/` root hub
2. `dev/docs/` (architecture, platform guides, release runbook, research; preserving `docs/evals/`, `docs/design/`, `docs/screenshots/`, `docs/smoke/`)
3. `dev/versions/` (milestone `NOTES_v*.md`, `CHANGELOG.md`, `snapshots/`)
4. `dev/analytics/` (`build_telemetry.jsonl`, `dev_brain_eval_history.jsonl`, harness notes)
5. `dev/agents/` (`INSTRUCTIONS.md`, `hooks/`, `skills/`, `behavior/`, `roles/`, `evals/`) with live bridges in `.agents/`, `AGENTS.md`, `CLAUDE.md`, `.gemini/antigravity.md`
6. `dev/plans/<plan-slug>/` (`v1.md`..`vN.md`, `tasks.md`)
7. `dev/brain/` (`BRAIN.md`, `registry.yaml`, committed `brain_index.sqlite`, `scripts/dev_brain.py` search + monitor + accuracy eval suite)
