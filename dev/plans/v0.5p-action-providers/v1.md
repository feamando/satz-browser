Archived from Antigravity workspace design notes covering the per-profile ordered **Default Action Provider Registry**:

1. **Ranked Priority Lists & Built-in Vertical Categories (`satz_providers.py`):**
   - `search.general`, `search.knowledge`, `search.travel`, `search.accommodation`, `maps.navigation`, `commerce.tech`, `commerce.clothing`, `commerce.food`, plus user custom categories.
   - URL safety validation (`http`/`https` only; rejects `javascript:`, `file:`, `data:`, metadata IPs).
2. **Strict Vault Secret Isolation (`satz_passwords.py`):**
   - Secrets (`<SERVICE>_API_KEY`, login passwords, cookies) remain inside encrypted `profiles/<id>/vault.enc` and wipe cleanly on `lock_profile`. Agents inspect only masked status (`api_key | login | token_or_cookie | none | locked`).
3. **Search API Drivers, Comparer Integration & Safety Gates (`satz_web_harness.py`):**
   - `get_default_providers` read tool, `propose_set_default_provider` confirmation-gated preference tool, automatic failover across `#1 -> #2`, and `BehaviorMiner.mine_provider_suggestions` after `>= 3` domain sessions.
4. **Verification Suite:** `sidecar/test_providers.py` (`test_web_harness.py`, `test_unsubscribe_actor.py`, `test_m22.py`).
