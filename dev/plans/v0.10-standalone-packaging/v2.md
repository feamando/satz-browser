Full architecture specification imported from approved implementation plan:
- **Relocatable Sidecar Runtime:** `sidecar/requirements-runtime.txt`, `scripts/prepare_sidecar_bundle.py` (`python-build-standalone` 3.12 + CPU PyTorch on Windows / MPS on macOS, `--sidecar-only`, stripping `test_*.py`/`__pycache__`), and `src-tauri/tauri.bundle.conf.json`.
- **Rust Resource & Self-Update Safety:** `src-tauri/src/lib.rs` preserves local `.venv`/`..\sgs\.venv` priority inside Git checkouts while falling back to `resource_dir()` in installed bundles (`PYTHONNOUSERSITE=1`, `PYTHONUTF8=1`), and exposes `prepare_for_update` (`UPDATE_SHUTDOWN` flag + sidecar tree termination) before `tauri-plugin-updater` replaces binaries.
- **Persistence Separation:** User AppData (`%APPDATA%\com.satz.browser\` on Windows, `~/Library/Application Support/com.satz.browser/` on macOS) preserves `satz.db`, `planck_store.sqlite`, `vault.enc`, `BRAIN.md`, Hugging Face `models/`, and `dev/analytics/telemetry.sqlite` across upgrades.
- **CI & Install Guides:** `.github/workflows/release.yml`, `scripts/build_preview.ps1`, `scripts/build_preview.sh`, `src/updater.ts`, Ed25519 `TAURI_SIGNING_PRIVATE_KEY`, and macOS unsigned gatekeeper instruction (`xattr -cr /Applications/satz.app`).
