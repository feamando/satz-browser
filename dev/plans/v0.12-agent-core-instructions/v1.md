## 1. Objective
Establish `dev/agents/` as the canonical single source of truth for Antigravity and Claude Code instructions, specifically governing **core development flows** (frontend tokens/i18n, Rust WebView2/WKWebView shell, sidecar/Planck independence, Dev Brain sync) and **release management** (3-manifest semver alignment, `release_gate.py`, relocatable Python staging, Windows/macOS installer bundling, Ed25519 updater signing, GitHub Actions CI, and `xattr -cr` macOS preview handling).

## 2. Subfolder Architecture under `dev/agents/`
- `INSTRUCTIONS.md`, `core_dev_flows.md`, `release_management.md` — concise root rules + deep playbooks under the 24 KB Antigravity budget.
- `hooks/` — `hook_runner.mjs`, `hook_common.py`, `session_start_context.py`, `pre_invocation_context.py`, `pre_tool_guard.py`, `post_edit_brain_sync.py`, `stop_gate_check.py`, `pre_commit_dev_sync.py`, `release_gate.py` (wired into `.agents/hooks.json` & `.claude/settings.json`).
- `skills/` — progressive-disclosure `SKILL.md` bundles (`satz-release-manager`, `satz-dev-brain`, `satz-eval-auditor`) wired via `.agents/skills.json`.
- `behavior/` — `developer_patterns.yaml` & `behavior_log.jsonl` recording cross-OS and packaging preferences.
- `roles/` — `roles.yaml` defining coordinator/subagent ownership (`release-manager`, `platform-verifier`, `dev-brain-architect`, `eval-security-auditor`).
- `evals/` — `error_log.jsonl`, `agent_eval_cases.yaml`, and `dev_brain_eval_cases.json`.
