## 1. Objective (v2 Expansion)
Upgrade `dev/agents/` from static guidance into an active, enforced dual-harness automation layer across **Antigravity** (`.agents/hooks.json`) and **Claude Code** (`.claude/settings.json`) with automated skill synthesis, background error-to-eval loops, core subsystem skills, release/version automation, and binary snapshot history.

## 2. Implemented Capabilities
1. **Cross-Platform Lifecycle Hooks (`dev/agents/hooks/`):**
   - `hook_runner.mjs` resolving repo root cleanly across `.agents/` and `.` cwds while bypassing Windows Store `python3.exe` stubs.
   - `session_start_context.py` dynamically loading all `dev/agents/skills/*/SKILL.md` frontmatter, active plans, pending skill proposals, eval alerts, and Dev Brain status.
   - `pre_invocation_context.py` deduplicating prompts, injecting Dev Brain skill + context recommendations, and capturing prompt telemetry.
   - `pre_tool_guard.py` enforcing read-only `../sgs`, CSS tokens, UI em/en-dash ban, private key protection, and manifest semver parity on `git tag`.
   - `post_edit_brain_sync.py` syncing Dev Brain on `dev/` edits and logging tool/error telemetry.
   - `stop_gate_check.py` auto-reindexing stale `dev/` files, catching broken graph links / dirty UI regressions, logging turn errors, and spawning the detached background worker.
2. **Core Skill Catalog & Version CLI:**
   - Added `satz-ui-design-i18n`, `satz-cross-platform-shell`, `satz-sidecar-models-boundary`, `satz-tools-safety-boundary`, and `satz-feature-planner`.
   - Upgraded `satz-release-manager` with `scripts/release_version.py` (`major`, `minor`, `fix`, model manifest checksum verification, and changelog/snapshot integration).
3. **Background Behavior-to-Skill & Error-to-Eval Pipeline:**
   - `behavior_eval_store.py` (gitignored SQLite capture) + `scripts/agent_background_worker.py` (`proposals/<slug>/SKILL.md`, `rule_candidates.json`, `auto_eval_cases.yaml`, `eval_history.jsonl`, `approve`/`reject`).
